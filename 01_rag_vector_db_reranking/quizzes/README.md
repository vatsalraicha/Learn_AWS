# Quizzes — RAG, Vector DBs & Reranking

Take these cold, then check against the answer key. The point is to find what you don't know, not to score 100%.

## How to take them

1. **One module at a time.** Don't bulk it.
2. **Closed book.** No peeking at the module doc, FACTS.md, or web search.
3. **Write down your answer**, even if rough. The act of articulating reveals fuzz that "I think I know this" hides.
4. **Then** open the answer key. Mark each as 🟢 confident-correct, 🟡 partial, 🔴 missed.
5. Re-read the module's section for any 🔴 / 🟡.

## Question types

- **Recall** — "name the four reflection tokens in Self-RAG"
- **Apply** — "given this scenario, which reranker would you choose?"
- **Diagnose** — "this metric pattern looks like which failure mode?"
- **Defend** — "you'd add HyDE here. Convince me."

The defend questions are the hardest and most valuable. Job interviewers ask exactly those.

## Scoring rubric (loose)

| % | Reading |
|---|---------|
| 90+ | Solid grasp; ready to teach. |
| 70-89 | Working knowledge; will hold up in interviews on most questions. |
| 50-69 | Familiar; need to re-read 2-3 modules. |
| < 50 | Re-read whole topic with notes. |
