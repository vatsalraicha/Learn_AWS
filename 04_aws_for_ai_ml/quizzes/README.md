## Question style (following Topics 02 & 03 convention)

Each quiz includes a mix of:
- **Recall** — atomic facts (e.g., "What's the difference between a Security Group and a NACL?")
- **Apply** — small scenario problems (e.g., "Design a VPC for a HIPAA-style SageMaker workload")
- **Diagnose** — failure-mode questions (e.g., "Why might a SageMaker notebook in VPC mode fail to reach S3?")
- **Defend** — architecture-decision questions (e.g., "When would you pick KServe-on-EKS over a SageMaker endpoint?")
