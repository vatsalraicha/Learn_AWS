## Question structure

Each quiz uses four cognitive levels (per project convention from Topic 04):

- **Recall** — atomic facts, definitions, table values
- **Apply** — given a scenario, produce a config/decision
- **Diagnose** — given a symptom, find the cause
- **Defend** — argue for/against a choice (architect lens)

Answers follow each section with **explanations** so a wrong answer becomes a teachable moment.

## How to use

1. **Take cold, no peeking.** Aim ~2 min/question (matches exam pace of 90 min / 45 Qs).
2. **Score yourself** per quiz. 70% per quiz ≈ exam-ready for that domain.
3. **Re-read the module** for any question you missed. Module numbers cross-reference each question.
4. **One week before exam** — take all 136 in one timed sitting (4.5 hours, or split AM/PM). If composite ≥ 80%, you're solid.

## What 70% looks like

The official exam cut score is **~70%** (community consensus; Databricks does not publish). To hit 70% you must be **strong in 3 + 4** (52% of the exam) and **competent in 6** (the new 2026 stuff). Section 5 is only 8% — don't over-invest.

## Format conventions

- **Single-answer** questions list options A–E.
- **Multi-select** questions are marked `[select N]` and require all correct options.
- Some questions are pure recall (e.g., "What does CDF stand for?"); others are full scenarios.
- Code snippets are realistic Databricks SDK / SQL / MLflow.
