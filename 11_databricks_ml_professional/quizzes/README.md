## Question types — the four levels

Adapted from the corpus convention:

| Type | What it tests | Time |
|---|---|---|
| **Recall** | Fact retrieval — API names, percentage thresholds, test mappings | <1 min |
| **Apply** | Pick the right tool/test/strategy for a scenario | 1-2 min |
| **Diagnose** | Walk through troubleshooting an issue | 2-3 min |
| **Defend** | Argue for/against a design choice; identify what's wrong | 2-3 min |

The real Databricks exam is predominantly **Apply** with some **Recall**. We over-index on Diagnose / Defend because building those muscles makes the Apply questions feel easy.

## How to use these quizzes

1. **First read-through** — work the quizzes module-by-module *after* finishing each module. Quiz 01 modules 01-06; Quiz 02 modules 07-13; Quiz 03 modules 14-16.
2. **Cold pass** — once you've read all modules, take all three quizzes back-to-back as if it were exam day. ~3 hours total. No peeking.
3. **Score yourself.** Target: > 80% on each section. Below 80% → re-read the relevant modules and re-quiz a week later.
4. **Diagnose your mistakes.** Were they recall gaps (re-read FACTS.md), apply gaps (re-read the module), or trap gaps (review the ⚠️ callouts)?

## Scoring guidance

- < 60% — you have notable gaps. Re-read modules; don't schedule the exam yet.
- 60-75% — solid foundation, but borderline. Several focused review passes before scheduling.
- 75-85% — likely pass band. Focus on the wrong-answer reasons.
- > 85% — schedule the exam confidently.

The real exam is 59 questions in 120 minutes — ~2 min/question. Practice this pace.

## After each quiz

Look at the wrong answers and ask:

1. Was this a fact I didn't know? → FACTS.md.
2. Was this a concept I didn't fully grasp? → Re-read the module.
3. Was this a distractor I fell for? → Note the exam-trap callout.
4. Was this a phrasing trick? → Slow down on reading; circle the verbs in the question.

Good luck.
